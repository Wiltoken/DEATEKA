## Cómo navegar esta documentación

1. **Si recién llegás al proyecto**, empezá por el [README](../README.md) raíz.
2. **Si vas a desarrollar**, leé [Arquitectura](arquitectura.md) y luego el
   [Manual técnico](manual-tecnico.md).
3. **Si vas a operar la tienda**, usá el [Manual de usuario](manual-usuario.md).
4. **Antes de contribuir**, seguí las reglas de [Control de versiones](control-de-versiones.md).
